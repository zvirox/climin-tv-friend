# Climin UI v0.0.2 — release notes

**Date:** 2026-10-27
**Version:** 0.0.2 (versionCode 2)
**Package:** `io.climintv.home`
**Min / target SDK:** 26 (Android 8.0) / 34 (Android 14)

## What this release is

The theme release. Glass UI — the look the launcher shipped with — becomes one of **five selectable
looks**, switched live from **Settings › Theme**:

| Style | What it is |
|---|---|
| **Glass UI** (default) | The original liquid glass, kept pixel-identical |
| **Material 3 Expressive** | Tonal containers, purple seed, tinted focus, 28 / 16 px radii |
| **Win UI** | Frosted acrylic, thin strokes, Segoe blue, rectangular focus, 8 px radii |
| **Cyberpunk** | Near-black panels, glowing cyan hairline, 2 px chamfer |
| **Retro UI** | Flat beige plastic by day, warm CRT at night, hard offset block, square corners |

A look changes palette, surface recipe and shape — never motion, geometry, icons, navigation or
type. The screensaver, the sleep-timer pill and the toast follow the look too.

Alongside it: a rebuilt settings layout (nine panes, with Theme, About, Shelf, Top Buttons, Remote
Buttons and a screensaver Preview), and five top buttons on the home screen.

Full detail: [docs/changelog.md](../changelog.md).

`launcher/build-and-install.sh` to take the Home role. Upgrading from 0.0.1 keeps settings.

## Installation

```bash
# as a normal app
adb install -r Climin-UI-v0.0.2.apk
adb shell am start -n io.climintv.home/.MainActivity

# or: build, install, prove it starts, then take the Home role
TV_HOST=<tv ip> ./launcher/build-and-install.sh
```

## Notes

- **TMDB key**: the home picks need a free TMDB API key in `Config.TMDB_KEY`. Without it the home
  screen shows the clock, weather and prices instead of the pick row.
- **Verified on** a TCL Android 9 (API 28) TV at 1280×720: home, drawer, settings, all five looks by
  day and by night, All Apps, screensaver, sleep pill.
- **Not verified on hardware** this cycle: the Android 11 – 12L screensaver variant
  (`ScreensaverAlone`) and the Android 8 – 10 dream path.
- Glass UI was held to a 0-pixel diff against the previous rendering for every screen touched.

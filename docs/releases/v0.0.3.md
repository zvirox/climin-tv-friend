# Your UI v0.0.3 — release notes

**Date:** 2026-10-30
**Version:** 0.0.3 (versionCode 3)
**Package:** `io.yourtv.home`
**Min / target SDK:** 26 (Android 8.0) / 34 (Android 14)

## What this release is

The rename release. **Climin TV Friend** is now **Your TV Friend**, and the launcher **Climin UI** is
now **Your UI**. Every screen, motion, geometry, icon, navigation rule, setting and feature is
unchanged; only the names and the Android package moved.

- App label, Settings › About, screensaver name (`Your Ambient Clock`), remote-key helper names and
  all 26 translations say **Your UI**.
- Package `io.climintv.home` → `io.yourtv.home`; photo provider authority
  `io.yourtv.home.photos`; app data under `/sdcard/Android/data/io.yourtv.home/files/`.
- Logcat tag `YourUI`; release assets are `Your-UI-v0.0.3.apk` and its `.sha256`.
- Tools (`photos.py`, `manage.py`, `theme.sh`, `trace.py`, update/restore scripts) default to the new
  package and authority.

Full detail: [docs/changelog.md](../changelog.md).

## Upgrading from Climin UI

**This is a different app to Android.** `io.yourtv.home` cannot upgrade `io.climintv.home`, and the
old app's settings, pinned apps, photos and Home role are not carried over. Install 0.0.3, set it as
Home, check it, then uninstall the old package:

```bash
adb install -r Your-UI-v0.0.3.apk
adb shell am start -n io.yourtv.home/.MainActivity

# or: build, install, prove it starts, then take the Home role
TV_HOST=<tv ip> STOCK_LAUNCHER=none ./launcher/build-and-install.sh

# photos again, with the new package and provider
TV_HOST=<tv ip> tools/venv/bin/python -I tools/photos.py photos/*.jpg

# when 0.0.3 owns Home
adb uninstall io.climintv.home
```

The 0.0.2 release keeps its published name and tag — **Climin UI v0.0.2** — and its asset is
`Climin-UI-v0.0.2.apk`; see [v0.0.2.md](v0.0.2.md).

## Assets

The release workflow builds the APK from the `v0.0.3` tag and attaches it as
`Your-UI-v0.0.3.apk` (also as `app-release.apk`): 1,405,512 bytes, SHA-256
`c4c67e3683ed5efcc4b91e65ad2df33371fff9113cc7ade75f31f1c834d504ab`, which is also in
`Your-UI-v0.0.3.apk.sha256`.

The APK is signed with the debug keystore, so it installs as a normal app. It is not a store signing
key, and each workflow run creates its own debug key: installing one release over another signed by
a different key fails with `INSTALL_FAILED_UPDATE_INCOMPATIBLE`. Uninstall first (which clears
settings) or build from this source with `launcher/build-and-install.sh`.

## Notes

- **TMDB key**: the home picks need a free TMDB API key in `Config.TMDB_KEY`. Without it the home
  screen shows the clock, weather and prices instead of the pick row.
- **Verified on hardware** (Xiaomi MiTV, Android 9 / API 28, 1280×720) on the day of release: fresh
  install of `io.yourtv.home`, Home role over FreeMyTV, label **Your UI** and v0.0.3 in Settings,
  home screen with For You picks and shelf, Settings panes, the screensaver (clock, backdrop and
  picks), and a clean crash buffer. Older settings carried by **Climin UI** stayed with
  `io.climintv.home`, which was uninstalled afterwards.
- The Android 11 – 12L screensaver variant (`ScreensaverAlone`) and the Android 8 – 10 dream path's
  shader clock fall back to a gradient below Android 13 (`RuntimeShader`), as designed.
